Тестовое задание для стажёра Backend-направления (зимняя волна 2025)

  - Golang 1.26.5: net/http, pgx/v5

  - Migrations: golang-migrate

Написал сервис для простенького портфолио, тренировки, веселья и в некотором роде шаблона вариантов решения определённых задачек. Старался не использовать ИИ(Кроме как на рутинные задачи), дабы пошевелить мозгами и понять что помню, а где нужно повторить/поизучать.

В планах по мере возможности и времени доработать сервис.
